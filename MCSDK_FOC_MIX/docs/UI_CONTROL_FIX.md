# Qt 拖动控件修正记录

## 问题原因

### 速度滑块

原实现把 `QSpinBox::valueChanged` 直接连接到速度命令。滑块每移动一个刻度
都会触发一次命令，同时 20 Hz 遥测又把固件斜坡过程中的瞬时速度参考写回
滑块。因此拖动期间会出现滑块回跳、手感发涩，以及串口命令队列频繁更新。

### 位置圆盘

圆盘选择目标后，下一帧遥测仍可能携带选择前的旧目标。原实现无条件把该
目标写回橙色指针，导致指针在拖动或等待提交时跳回。圆盘也没有单独保存
拖动状态，且圆盘外侧的点击仍会参与角度计算。

## 修改

- 速度滑块拖动时只更新本地数值；释放滑块或点击“应用转速”后发送一次
  速度命令。“回零速”会设置 0 RPM 并立即提交。
- 用户编辑速度目标后，遥测只更新左侧实时参考卡片，不覆盖控制滑块。
- 位置圆盘增加按下、拖动、释放状态，并限制鼠标必须位于有效圆环区域。
- 本地选中的位置目标不会被周期遥测覆盖；圆盘拖动期间只更新橙色目标
  指针，松开鼠标时发送一次位置命令。数字输入仍通过“转到该角度”提交。
- 切换控制模式或重新连接时会重新同步本地控件状态。

本次仅修改源码并进行静态一致性检查，没有执行 Qt 或固件编译。
