# MCSDK 原生直接转矩位置环修正

## 控制结构

本工程继续使用 MCSDK 原生位置控制：

```text
位置误差 -> MCSDK Position PID -> 转矩/Iq 参考 -> 电流环
```

没有使用参考工程的“位置环输出速度参考”串级控制。

## 震动原因

原位置环参数为：

```text
Kp = 10000 / 1024
Ki = 1000 / 32768
Kd = 1000 / 16
位置环频率 = 1000 Hz
位置环输出限幅 = 2 A
```

编码器为 `1024 PPR`，四倍频后每圈 `4096` 个计数；MCSDK 机械角每圈为 `65536` 个单位，因此一个编码器计数对应 `16` 个位置误差单位。

当前电流换算约为 `595 digit/A`，`2 A` 输出限幅约为 `1190 digit`：

- `1°` 误差约为 `182` 个角度单位。
- 原 P 项输出约为 `182 * 10000 / 1024 = 1777 digit`。
- 因而约 `0.67°` 的误差就会达到满 `2 A`。
- 编码器仅跳动一个计数时，原 D 项输出为 `16 * 1000 / 16 = 1000 digit`，约等于 `1.68 A`。

所以对齐结束后，编码器计数变化会让位置环快速输出正负大电流，造成剧烈震动。

## 当前修正

第一轮保守参数为：

```text
Kp = 64 / 1024
Ki = 0 / 32768
Kd = 64 / 16
位置环最大输出电流 = 0.5 A
```

实机反馈表明第一轮参数已经消除失控，但仍有稳态误差和较明显震动。第二轮参数调整为：

```text
Kp = 48 / 1024
Ki = 4 / 32768
Kd = 8 / 16
位置环最大输出电流 = 0.5 A
```

- 加入很小的 Ki，用于逐步消除摩擦和负载造成的稳态误差。
- Kd 从 `64` 降到 `8`，单个编码器计数造成的 D 项电流脉冲约从 `0.107 A` 降至 `0.013 A`。
- Kp 从 `64` 降到 `48`，降低位置刚度和机械共振激励。
- 新轨迹开始前只复位 D 项历史，保留已经建立的积分负载补偿。

同时修正启动时序：

1. 编码器对齐结束、状态首次进入 `RUN` 时，清除位置 PID 的积分项和上一次误差。
2. 清除对齐前建立的旧轨迹。
3. 将位置目标设置为对齐完成后的当前位置，实现无扰动接管。
4. 固件拒绝在 `RUN` 前执行位置命令。
5. Qt 在 `RUN` 前禁用位置输入、点动、回零和保持位置控件。
6. 位置运动时间下限设为 `100 ms`，避免界面把阶跃目标送入原生 Follow 模式。
7. 新目标到来时先终止旧轨迹，再从当前实际位置生成新的原生 MCSDK 轨迹。

## 建议调参顺序

首次测试保持空载，并保留 `0.5 A` 限幅：

1. 从第二轮 `Kp=48、Ki=4、Kd=8` 开始，只进行 `2°~5°` 小步进。
2. 如果仍有高频震动，先将 Kd 降为 `4` 或 `0`，不要先改 Ki。
3. 如果出现缓慢的往复摆动，将 Ki 从 `4` 降为 `2`。
4. 如果稳定但响应太软，逐步增加 Kp，例如 `48 -> 64 -> 80`。
5. 如果稳定后仍有同方向稳态误差，再将 Ki 从 `4` 小步增加。
6. 最后才逐步提高 `POSITION_MAX_CURRENT_A`，不得先恢复到 `2 A`。

## 编译状态

按用户要求，本次修改后没有执行 Qt、Keil 或固件编译。
