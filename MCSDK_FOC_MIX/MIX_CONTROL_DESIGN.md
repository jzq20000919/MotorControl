# 速度/位置控制合成与切换说明

## 合成原则

本工程没有把位置环套在速度环外面。两种模式共享底层 FOC 电流环，
但在中频控制任务中只有一个上层调节器能够写入转矩参考：

1. 速度模式：`PositionControlRegulation=false`，由 MCSDK
   `MCM_SPEED_MODE` 和原生速度 PI 计算转矩参考。
2. 位置模式：`PositionControlRegulation=true`，由
   `TC_PositionRegulation()` 中的原生位置 PID 直接计算转矩参考，并将
   STC 置为 `MCM_TORQUE_MODE`。

这样可以避免速度 PI 和位置 PID 同时写入转矩参考，也符合“位置环直接
输出转矩参考、不使用参考工程串级环”的要求。

## 无扰切换

速度转位置：先读取编码器的当前多圈机械角度，将 `Theta`、`ThetaPrev`
都设为该角度，清空运动轨迹和位置 PID 历史，再启用位置调节。切换后的
初始位置误差为零。

位置转速度：先关闭位置调节并清空其轨迹/PID，再下发 0 RPM 的速度斜坡，
使 STC 恢复原生速度模式。Qt 收到模式遥测确认后显示相应页面。

## MCP 用户命令（协议版本 2）

| 命令 | 功能 | 参数（小端） |
|---|---|---|
| 0 | 获取遥测 | 无 |
| 1 | 设置模式 | `uint8 mode`，0 速度 / 1 位置 |
| 2 | 设置速度 | `int16 rpm` + `uint32 duration_ms` |
| 3 | 设置位置 | `int32 cdeg` + `uint32 duration_ms` |
| 4 | 启动电机 | 无 |
| 5 | 停止电机 | 无 |
| 6 | 故障确认 | 无 |
| 7 | 旧版回零命令 | 已禁用；Qt 使用带时长的最近路径 0°位置命令 |
| 8 | 保持当前位置 | 无，仅位置模式且电机 RUN |

所有成功命令均返回 48 字节 `FOC1` 遥测块和 MCP 成功状态字节。遥测中的
模式、状态、故障、电流、速度参考、实测速度、目标位置和当前位置用于
Qt 页面同步；Qt 会检查协议版本是否为 2。

## 2 A 位置限制

`Inc/drive_parameters.h` 中 `POSITION_MAX_CURRENT_A` 已设为 `2.0F`，
`Src/mc_config.c` 同时用该宏限制位置 PID 的积分项和最终输出，因此限制
不是仅在 Qt 显示层实现，而是在固件转矩参考生成处生效。

## 静态检查范围

- Keil 工程已包含 `mc_app_hooks.c` 与 `foc_app_protocol.c`。
- CubeMX/Workbench/Keil 项目名和输出名已改为 `MCSDK_FOC_MIX`。
- Qt 默认串口波特率已改为 1,843,200，并同时通过 Windows 注册表和 DOS
  设备表枚举 COM 口。
- MCP 请求先单独写入 4 字节 ASPEP 包头，调用 `FlushFileBuffers()` 确认
  包头已离开 Windows 缓冲区，等待 2 ms 后再写负载，以保留此前已验证的
  NACK/命令超时修复。
- 速度滑块拖动时只更新本地预览，释放滑块或点击“应用转速”时才发送一次
  命令；遥测不再用斜坡中的瞬时参考值抢占用户正在编辑的控件。
- 位置圆盘只接受圆盘有效区域内的鼠标操作，本地目标不会被旧遥测覆盖；
  拖动期间只预览，松开鼠标时提交一次最近多圈位置命令。
- 按要求未执行任何固件或 Qt 编译。
